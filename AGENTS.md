## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on neithanmo/transaction-engine via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Spec review

The spec is the issue **plus** every ADR in `docs/adr/` and the README's Assumptions and Input and errors sections. Give all of them to the spec reviewer, which checks the diff against each constraint they state.
